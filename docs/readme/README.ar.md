عارض سريع يعمل محليًا لسجل جلسات البرمجة بالذكاء الاصطناعي، مبني كتطبيق جزيرة
[Astro](https://astro.build) ويُشحن إلى سطح المكتب عبر
[Deno Desktop](https://docs.deno.com/runtime/desktop/) (‏Deno ‏≥ 2.9).

يقرأ النصوص مباشرة من القرص. بلا خدمة خلفية، بلا حساب، بلا تتبّع.

![سجل الجلسة مع بطاقات أدوات قابلة للتوسيع](../screenshots/sessions.jpg)

## الوكلاء المدعومون

| الوكيل | يقرأ من | استدعاءات الأدوات |
|---|---|---|
| Claude Code | ملفات JSONL في `~/.claude/projects` | نعم |
| Codex CLI | ملفات JSONL في `~/.codex` | نعم |
| GitHub Copilot | سجلات `chatSessions` في VS Code | نعم |
| OpenCode | مخزن SQLite | نعم |
| Cursor | ‏`state.vscdb` (‏`cursorDiskKV`) | نعم |
| Goose، Zed، Amazon Q، Kiro، ForgeCode | SQLite | متفاوت |
| Gemini CLI، Cline، Aider، Continue، Qwen وغيرها | ملفات | نص فقط |

كل وكيل يُحوَّل إلى نموذج زمني واحد، فيبدو العارض متطابقًا مهما كانت الأداة
التي أنتجت الجلسة.

## البدء السريع

```bash
pnpm install

pnpm dev            # خادم التطوير للويب
pnpm check          # فحص وتنسيق وأنواع واختبارات (100٪) وبناء
```

### سطح المكتب (Deno)

```bash
pnpm desktop        # ابنِ مرة واحدة ثم صرّف وشغّل تطبيق سطح المكتب
pnpm desktop:dev    # غلاف سطح مكتب حول خادم التطوير (إعادة تحميل حية)
pnpm desktop:build  # إنتاج dist/AIManager.app
```

يكتشف Deno إطار Astro تلقائيًا، ويضمّن `dist/`، ويشغّل خادم محوّل Node داخل
بيئة Deno؛ وتُعرض الواجهة في عارض الويب الخاص بالنظام.

## الميزات

- تصفح المشاريع والجلسات مع عوامل التصفية والمعاينات والعناوين المخصصة
- عرض غني للنصوص: ماركداون، شيفرة ملوّنة، تفكير قابل للطي، بطاقة لكل أداة مع
  فروقات موحّدة، قوائم مهام، صور، ومخرجات قياسية
- مفتاح لعرض نشاط الوكلاء الفرعيين، وتحميل تدريجي للمزيد
- بحث نصي كامل عبر كل المشاريع مع الانتقال إلى الرسالة
- تحليلات الرموز والتكلفة: النماذج، الأدوات، خريطة النشاط، أبرز الجلسات
- تصدير الجلسات بصيغة Markdown أو JSON
- ست لغات للواجهة مع دعم الاتجاه من اليمين إلى اليسار وقواعد جمع صحيحة لكل لغة
- التحقق من التحديثات عبر تغذية إصدارات موقّعة
- مظهر داكن أو فاتح أو حسب النظام، وبحث بلوحة المفاتيح (`/`، ⌘K)

## التوطين

تعيش ملفات اللغات في `src/i18n/locales/<lang>/<namespace>.json`. إضافة لغة تعني
مجلدًا جديدًا ومدخلًا واحدًا في `src/i18n/config.ts`؛ اضبط `dir: 'rtl'` وسينعكس
التخطيط تلقائيًا، لأن الأنماط تستخدم خصائص منطقية (`ms`/`me`، `ps`/`pe`،
`text-start`) بدل الفيزيائية.

يتحقق اختبار من أن كل لغة تشحن المفاتيح نفسها، وأن لا شيء فارغًا، وأن أي ترجمة
لا تُدخل متغيرًا لم تعرّفه الإنجليزية. الطوابع الزمنية النسبية تأتي من
`Intl.RelativeTimeFormat`، فلا تحتاج مفاتيح إطلاقًا.

## التحديثات

`Deno.autoUpdate()` يُرقّع الملفات التنفيذية في مكانها، وهذا يكسر توقيع حزمة
macOS ([denoland/deno#36574](https://github.com/denoland/deno/pull/36574))، كما
أن ويندوز لا يستطيع تطبيق الرقع أصلًا. لذلك تُشحن التحديثات **كملفات كاملة**:
يقرأ التطبيق ملف `latest.json` واحدًا، ويتحقق من توقيع Ed25519 ومن SHA-256، ثم
يسلّم المهمة إلى المثبِّت ويخرج.

| النظام | مسار التثبيت |
|---|---|
| macOS | مساعد ينتظر الخروج، ثم `ditto` يفك الحزمة ويعيد التشغيل |
| Linux | مساعد يبدّل ملف AppImage ويعيد التشغيل |
| Windows | ‏`msiexec` يتولى ملف `.msi` |

اضبط `UPDATE_FEED_URL` (و`UPDATE_PUBLIC_KEY` لطلب بيانات موقّعة). بدون تغذية
إصدارات لن يعرض التطبيق أي تحديث.
